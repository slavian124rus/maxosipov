## Найденные проблемы

### Высокие

**F1. Напоминание «Подписка закончилась» практически не уходило, а «Осталось 3 дня» уходило не вовремя.** Задача `subscriptions.expire` раз в час переводит истёкшие `trial/active` в `expired`, а `reminders.clients` выбирала только `trial/active` — к 10:00 нужных подписок там уже не было. Кроме того, «за 3 дня» слалось при любом остатке 0–3 дня (и сразу после конца: `ceil(−0,4) = −0` попадало в ветку «заканчивается») с фиксированным текстом «Осталось 3 дня».
Исправлено: «заканчивается» — ровно за 3 дня (`ceil = 3`, только `trial/active`); «закончилась» — для `expired` (и ещё не переведённых) подписок, закончившихся не больше 2 дней назад (чтобы после выкатки не сыпать по старым). Замороженные и отключённые не получают ничего. Тесты `reminders.test.ts` (в т.ч. повторный запуск задачи не дублирует — Review Focus 4 на уровне задачи, а не только `notify`).

**F2. Клиенту уходил push «Максим обновил программу» на каждый тап в редакторе.** Редактор шлёт патч на каждое действие (перетащил, поменял подходы, заметка), `program_updated` отправлялся с каждым патчем — правка из десяти действий давала десять push.
Исправлено: `notifyThrottled` — не чаще одного такого уведомления на клиента за 30 минут. Тест.

**F3. У тренера не было способа включить push.** Карточка «Включи уведомления» была только в клиентских экранах; Максим не получил бы ни жалобы на боль, ни утреннюю сводку.
Исправлено: `PushOptIn` на экране «Сегодня» и в «Ещё» кабинета (по кнопке, на iPhone — подсказка про установку PWA).

**F4. Адрес push-подписки не проверялся — SSRF.** Любой вошедший клиент мог прислать `endpoint` вида `http://внутренний-адрес/…`; сервер потом сам делал на него запрос при отправке уведомления.
Исправлено: `subscribePush` принимает только https-адреса push-сервисов браузеров (FCM, Mozilla, Apple, Windows Push), без порта и логина в адресе; длина ключей ограничена. Тест на 10 плохих и 4 хороших адреса.

### Средние

**F5. Откат помечал `reverted` все принятые предложения программы.** Включая более ранние и включая случай, когда откатывалась собственная правка Максима.
Исправлено: только для изменения МаксИИма и только последнее принятое предложение. Два теста.

**F6. `assignTemplate` не был атомарным** (отклонение от плана: «в одной транзакции»). При ошибке на втором клиенте первый уже получал шаблон.
Исправлено: одна транзакция на всех (порядок по `id`, чтобы параллельные вызовы не блокировали друг друга), повтор при гонке за «одну активную программу». Заодно `copyTemplateToClient` проверяет, что клиент из того же зала и не удалён. Три теста (успех, нет прав на одного, клиент не найден).

**F7. Лента «Приняли изменения МаксИИма»: `limit` применялся раньше проверки прав.** Тренер с областью `own` мог не увидеть своё изменение, если у других тренеров накопилось 20 свежих.
Исправлено: область, зал и «программа тренера» — в самом запросе, `limit` режет уже отфильтрованное. Тест (25 чужих + 1 свой).

**F8. «Заканчивается доступ» без фильтра статусов.** В ленту попадали замороженные и отключённые подписки (по плану — только `trial|active`), запрос не ограничивался видимыми клиентами. Исправлено, тест.

**F9. Формы настроек, ролей и заметок глотали ошибки** (только `console.error`): Максим жмёт «Сохранить», ничего не меняется, причины не видно. Review Focus 5 был закрыт только для формы смены роли.
Исправлено: общий `ActionForm` — под формой «Сохранено» или текст ошибки. Показываются только русские сообщения (свои и из схем валидации, которые теперь тоже русские); английский текст драйвера БД наружу не уходит. Затронуты: МаксИИм, прогрессия, бренд, контакты, роли (создание и редактор), назначение тренера, заметки. e2e заметок и ролей проходят.

**F10. `setClientTrainer` ничего не проверял:** «тренером» можно было назначить клиента или несуществующий `id`, «клиентом» — сотрудника. Исправлено (роль, зал, удалённые), четыре теста.

**F11. Заметки тренера видел любой, у кого есть `clients.view`** (приватные заметки — для тех, кому разрешено `clients.notes`). Исправлено в `listNotes` и в карточке клиента. Тест.

### Низкие

**F12. Сводка тренеру считала жалобы за 7 дней, а лента — все неразобранные;** клиенты без назначенного тренера в сводку не попадали. Выровнено с лентой.

**F13. Статистика.** `getTrialConversion` читал всю таблицу `subscription_events` в память, считал по всему залу независимо от области прав и потерял докстринг у `listSubscriptionEvents`. Теперь читаются только пробы, закончившиеся в окне 90 дней, и выдачи их владельцев; расчёт сужен до видимых клиентов. Роль с `analytics.view`, но без `clients.view`, получает нули, а не 404. Четыре теста (положительная доля, окно 90 дней, область `own`, нет права на клиентов).

**F14. Редактор:** при ошибке сервера перетащенный порядок оставался на экране, хотя в базе его нет. Теперь возвращается состояние из базы.

**F15. e2e «Максим меняет схему» был нестабильным:** выборка `limit 1` без привязки ко дню брала произвольное упражнение с `order = 1` (в моём первом прогоне упал, после правки 22/22). Добавлена сортировка по дню.

## Замечания без правок (на решение владельца)

- Если задача напоминаний пропустит сутки, клиент не получит «за 3 дня» (текст по плану фиксированный). Устойчивее — динамический текст («Осталось 2 дня»), но это меняет тексты из плана.
- Откат изменения не шлёт клиенту push — клиент увидит правку, когда откроет программу.
- Подписка push привязана к последнему человеку, включившему её на устройстве, и не снимается при выходе из аккаунта: на общем устройстве уведомления могут уйти предыдущему человеку, пока новый не нажмёт «Включить». Предлагаю снимать подписку при выходе.
- Если push временно не ушёл (ошибка сервиса, не 404/410), плановое уведомление со своим `dedupe_key` повторно не отправится. Для напоминаний приемлемо.
- `getAiSpend`: итог за месяц — из `ai_usage_daily`, разбивка по моделям — из `ai_messages`; итоги тренировок и голос в разбивку не попадают, поэтому сумма строк меньше итога.
- «Сохранить как шаблон» использует `window.prompt`; в установленном PWA работает, но выглядит системно — лучше лист из дизайн-системы.
- В истории программы кнопка «Откатить» стоит у каждого изменения МаксИИма, хотя сработает только у последнего (ошибка понятная, Review Focus 2 выполнен).
- Голосовые запросы по-прежнему без суточного потолка (с ревью этапа 4).
- `getProgramAuthorKinds` больше никем не используется (экспорт остался).
