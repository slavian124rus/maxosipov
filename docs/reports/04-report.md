3. Спросить «Какой вес ставить на тягу верхнего блока?» — ответ идёт потоком, в углу — «МаксИИм».

## Отклонения от плана

- **`AI_*` и STT не сделаны жёстко обязательными в `env.ts`.** План говорит «обязательны», но жёсткая проверка ломает `pnpm build` и локальные прогоны без ключей (у исполнителя ключей нет). Вместо этого `getModel`/`getSpeechToText` бросают понятную ошибку, чат отвечает «МаксИИм сейчас недоступен…», голос — 503 «Распознавание речи не настроено». На сервере переменные всё равно нужно заполнить.
- `generateObject` в AI SDK 7 помечен deprecated (рекомендуют `generateText` + `output`). Оставлен по плану; предупреждение в логе.
- Добавлены роуты, которых нет в списке Files: `GET /api/coach/proposals` (карточки для чата), `GET /api/training/summary` (опрос итога), `POST /api/coach/voice` без `sessionClientUuid` (диктовка в чат).
- `ai_proposals.diff` оставлен `NOT NULL`: для `new_program` в `diff` и `payload` лежит один и тот же черновик; `payload` — источник истины.
- На экране завершения подходы из голоса пишутся через `enqueueSet` + `flushAll`: серверный `setExerciseFeeling` из браузера недоступен, ощущение уходит вместе с подходами.
- В `gym.settings` добавлено необязательное `aiPrices` (цена за 1k токенов по модели); без него стоимость = 0.
- e2e использует фейковый OpenAI-совместимый сервер (`e2e/fake-ai-server.ts`, порт 4010) через `webServer` в `playwright.config.ts`; настоящий провайдер в e2e не вызывается.
- Коммиты по задачам объединены в один `feat(ai): …` (`02a7f90`): задачи 1–5 связаны общими типами и схемой, промежуточные коммиты не собирались бы. Отчёт — отдельный `docs(reports)`.
