# Распознавание речи (STT) — этап 4

МаксИИм принимает голос двумя способами: диктовка вопроса в чате и «Наговорить, что сделал»
в тренировке (`ARCHITECTURE.md §9.7`). Аудио живёт только до распознавания: временный файл
удаляется сразу после ответа провайдера.

## Переменные окружения

```
STT_PROVIDER=plusvibe | yandex
STT_MODEL=<модель распознавания у plusvibeapi>   # нужен только для plusvibe
YANDEX_SPEECHKIT_KEY=<API-ключ>                  # нужен только для yandex
```

Переменные не обязательны на уровне `shared/env.ts` (иначе не собирается `pnpm build` без ключей),
но в production воркер при старте печатает в лог, чего не хватает (`missingAiEnv`). Без настройки
кнопка вернёт «Распознавание речи не настроено».

## plusvibe (OpenAI-совместимый)

Провайдер: `src/modules/coach-ai/stt/plusvibe.ts`.

- Запрос: `POST {AI_BASE_URL}/audio/transcriptions`, `multipart/form-data`
  (`file`, `model=STT_MODEL`, `language=ru`), заголовок `Authorization: Bearer AI_API_KEY`.
- **Проверка у plusvibeapi не выполнена:** на момент этапа в `.env` не было `AI_API_KEY`,
  поэтому наличие эндпоинта и модели распознавания не подтверждено. Перед включением
  `STT_PROVIDER=plusvibe` владельцу нужно отправить тестовый файл и убедиться, что
  `POST /audio/transcriptions` отвечает `{ "text": "..." }`. Если эндпоинта нет — переключиться
  на `yandex`.

## Yandex SpeechKit

Провайдер: `src/modules/coach-ai/stt/yandex.ts`.

- Синхронное распознавание `POST https://stt.api.cloud.yandex.net/speech/v1/stt:recognize?lang=ru-RU&topic=general`,
  заголовок `Authorization: Api-Key <YANDEX_SPEECHKIT_KEY>`, тело — аудио `ogg/opus`.
- Синхронный запрос ограничен ~30 секундами, поэтому запись до 2 минут режется `ffmpeg`
  на куски по 25 секунд (`-f segment -segment_time 25`) с перекодированием в `ogg/opus`,
  тексты кусков склеиваются.
- Документация: <https://yandex.cloud/ru/docs/speechkit/stt/request> (проверить при настройке:
  лимиты размера, формат `oggopus`, тарификация).

## Как проверить руками

1. Заполнить `.env`: `STT_PROVIDER`, ключ, при необходимости `STT_MODEL`.
2. `pnpm dev`, открыть тренировку на телефоне, нажать микрофон в шапке.
3. Сказать: «жим ногами три по двенадцать на сто двадцать, последний тяжело».
4. В таблице «Проверь» — упражнение из тренировки, 3 подхода 120 × 12, ощущение «Тяжело».
5. Сказать «тянуло поясницу» — должна появиться плашка «Остановись. Это лучше показать Максиму —
   я ему передал.», а Максиму — уведомление `client_pain`.

Проверка на реальных iPhone (Safari, установленное PWA) и Android (Chrome) требует ключа
провайдера и выполняется владельцем; результат — в `docs/reports/04-report.md`.
