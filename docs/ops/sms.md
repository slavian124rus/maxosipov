# СМС для входа по телефону

Провайдер выбирается переменной `SMS_PROVIDER`:

| Значение | Что делает |
|---|---|
| `console` | код печатается в лог, СМС не уходит (разработка, по умолчанию) |
| `smsru` | СМС.ру; нужен `SMS_API_KEY` |
| `smsaero` | SMS Aero; нужны `SMS_API_KEY`, `SMS_AERO_LOGIN`, по желанию `SMS_AERO_SIGN` |

## SMS Aero

1. Ключ: личный кабинет → Настройки → API-ключ → `SMS_API_KEY`.
2. `SMS_AERO_LOGIN` — логин, под которым вы входите в кабинет (обычно email). Авторизация — HTTP Basic: логин + API-ключ.
3. `SMS_AERO_SIGN` — имя отправителя. Пусто = бесплатное «SMS Aero»: годится для проверки, но для боевых кодов
   заведите своё имя в кабинете, иначе оператор может заблокировать сообщения. Все СМС проходят модерацию
   (до 5–10 минут), коды могут приходить с задержкой.
4. Стоимость одной СМС смотрите в кабинете → «Текущий тариф» (на 10.11.2026 около 9–14 ₽ по операторам).
5. Включить: `SMS_PROVIDER=smsaero`, перезапустить приложение и воркер.

Документация API: https://smsaero.ru/integration/documentation/api/
