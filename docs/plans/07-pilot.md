# Этап 7. Пилот в зале — план

> **Для исполнителя:** работай строго по `docs/plans/README.md`. Этот этап — немного кода (обратная связь, журнал ошибок) и в основном чек-листы. Пункты с пометкой **[владелец]** / **[Максим]** выполняют люди; исполнитель готовит для них инструкции и проверяет результат.

**Цель:** 5–10 реальных клиентов Колизея две недели тренируются в приложении; собираем замечания, исправляем, готовимся к запуску.

**Спека:** `ARCHITECTURE.md` §15–§16; `DESIGN.md` §6.2, §7.

## Global Constraints

- Во время пилота изменения выкатываются не чаще раза в день, вечером после 22:00 по Красноярску.
- Каждое исправление — отдельный коммит `fix(...)` с номером замечания `#Pnn` из `docs/pilot/feedback.md`.

## Review Focus

1. Клиент без интернета в подвальной части зала — тренировка не теряется.
2. iPhone старше iOS 16.4 — приложение работает без push, подсказка понятная.
3. Максим загружает 10+ роликов за вечер — очередь обработки не падает, сервер не перегружен.
4. Пробный период у пилотных клиентов заканчивается во время пилота — Максим продлевает без ошибок.
5. Клиент пишет МаксИИму что-то неожиданное (мат, не по теме) — ответ вежливый и короткий, без поломок.

### Задача 1. Обратная связь и журнал ошибок

**Files:** Create `src/modules/trainer/feedback.ts`, `src/modules/trainer/feedback.test.ts` (таблица `feedback(id, user_id, text, screen, user_agent, created_at, status)`), `src/components/app/feedback-button.tsx`, `src/app/(app)/app/trainer/settings/feedback/page.tsx`, `src/shared/log-error.ts`, `src/app/api/client-error/route.ts`, таблица `error_log(id, source 'server'|'client', message, stack, url, user_id, created_at)`.

- [ ] В профиле клиента и в «Ещё» тренера — «Сообщить о проблеме» (текст до 1000 символов, текущий экран подставляется автоматически) → запись + `notify` владельцу.
- [ ] `logError` в серверных обработчиках ошибок и `window.onerror`/`unhandledrejection` на клиенте (не чаще 10 записей в минуту с одного устройства) → `error_log`; страница для владельца со списком (последние 200).
- [ ] Тесты: длинный текст обрезается до 1000; лимит клиентских ошибок соблюдается. Коммит `feat(pilot): feedback and error log`.
