# Этап 6. Лендинг maxosipov.ru — план реализации

> **Для исполнителя:** работай строго по `docs/plans/README.md`. Можно выполнять параллельно с этапами 2–5 (зависит только от этапа 0; форма заявки использует `notify` из этапа 5 — если этап 5 ещё не сделан, заявка только сохраняется в БД).

**Цель:** одностраничный тёмный лендинг Максима: первый экран с видео, «что внутри приложения», МаксИИм, о Максиме, отзывы (только реальные), тариф «первый месяц бесплатно», три шага, контакты и карта; SEO под «персональный тренер Красноярск».

**Архитектура:** группа маршрутов `(site)`, статическая генерация (`export const dynamic = 'force-static'` для страницы; цена подтягивается при сборке и раз в час через `revalidate = 3600`). Все тексты — в одном файле `content/landing.ts`.

**Стек:** Next.js, Tailwind, Motion (появление блоков при прокрутке), Playwright (скриншоты экранов приложения для макетов).

**Спека:** `DESIGN.md` §10, §1–§5, §9.1; `ARCHITECTURE.md` §7 (`leads`), §16.

## Global Constraints

- Только реальные факты о Максиме, отзывы и фото — от владельца. В `content/landing.ts` всё, чего нет, помечается `null`; блок с `null` **не выводится** (не придумывать достижения, цифры клиентов и отзывы).
- Кнопки «Получить месяц бесплатно» → `${APP_URL}/login`.
- LCP < 2 с на мобильном 4G (Lighthouse mobile ≥ 90 по Performance, ≥ 95 по Accessibility и SEO).
- Видео первого экрана: ≤ 1,5 МБ, без звука, `poster` обязателен; на `prefers-reduced-motion` и `Save-Data` — только постер.
- Заявка: имя (2–60 символов), телефон (`normalizePhone`), обязательная галочка согласия; ≤ 5 заявок с IP в час.

## Review Focus

1. Медленный мобильный интернет → первый экран читается сразу, видео подгружается позже (проверка Lighthouse с троттлингом).
2. Нет реальных отзывов → блок «Результаты клиентов» отсутствует, разметка без пустых мест (тест задачи 1).
3. Цена не задана в админке → в тарифе «Первый месяц бесплатно, дальше — цену скажет Максим» (тест задачи 1).
4. Двойное нажатие «Отправить» → одна заявка (тест задачи 3).
5. Открытие `maxosipov.ru/app/...` → 404 (уже покрыто этапом 0; проверь e2e).

### Задача 1. Контент и разметка блоков

**Files:** Create `content/landing.ts`, `src/app/(site)/page.tsx` (переписать), `src/components/landing/*.tsx` (по одному файлу на блок), `src/components/landing/landing.test.tsx`.

**Interfaces — Produces:** `LANDING` со структурой:
```ts
{
  hero: { title: 'Тренируйся с Максимом'; subtitle: 'Персональный тренер · 10+ лет · Колизей, Говорова'; cta: 'Получить месяц бесплатно'; videoSrc: string; poster: string };
  inside: { title: 'Что внутри приложения'; items: { title: string; text: string; image: string }[] };   // 3 элемента: видео упражнений, мышцы на видео и фигуре, дневник с подсказкой веса
  coach: { title: 'МаксИИм — помощник в зале'; text: string; dialog: { from: 'client' | 'coach'; text: string }[] };
  about: { title: 'Обо мне'; photo: string | null; paragraphs: string[] | null; facts: string[] | null };
  reviews: { name: string; text: string; photo: string | null }[] | null;
  pricing: { title: 'Сколько стоит'; firstMonth: 'Первый месяц бесплатно' };
  steps: ['Войди через VK, Яндекс или по номеру', 'Ответь на 6 коротких вопросов', 'Тренируйся по программе Максима'];
  contacts: { address: 'Красноярск, ул. Говорова, зал «Колизей»'; phone: string | null; mapEmbedUrl: string | null };
}
```
Тексты `inside.items` и `coach` пиши сам — коротко, на «ты», по DESIGN §9 (3 пункта по 1–2 предложения; диалог — 4 реплики: «Собери тренировку на спину» → ответ МаксИИма в 2 предложения → карточка-предложение (рисуется компонентом) → «Принять»). `about`, `reviews`, `contacts.phone`, `mapEmbedUrl` — `null` до получения от владельца.

- [ ] **Шаг 1.** Тест `landing.test.tsx` (React Testing Library — добавь `@testing-library/react`, `jsdom` для этого файла): `reviews: null` → нет заголовка «Результаты клиентов»; `about.paragraphs: null` → блок «Обо мне» показывает только фото, если есть, иначе блок скрыт; цена `null` → текст «Первый месяц бесплатно, дальше — цену скажет Максим»; цена 2500 → «Первый месяц бесплатно, дальше 2 500 ₽ в месяц».
- [ ] **Шаг 2.** Блоки по DESIGN §10 в указанном порядке. Герой: на весь экран (`100svh`), видео-фон с затемнением снизу, заголовок `font-display` 56/40 px, подзаголовок, красная кнопка; «Что внутри» — 3 телефона-макета (рамка как в `prototypes/exercise-card/index.html`, внутри — скриншоты из задачи 2); МаксИИм — диалог с появлением реплик по очереди при прокрутке (Motion `whileInView`, 300 мс между репликами); «Как начать» — 3 шага с большими цифрами `font-display` красным; контакты — адрес, телефон текстом и кнопкой «Позвонить», карта (`iframe` Яндекс.Карт, если задан `mapEmbedUrl`, иначе — кнопка «Открыть в Яндекс Картах» на поиск адреса).
- [ ] **Шаг 3.** Шапка: монограмма «МО» + «Максим Осипов», справа маленькая кнопка «Войти» → `${APP_URL}/login`. Подвал: «Политика обработки персональных данных», «Согласие», © год.
